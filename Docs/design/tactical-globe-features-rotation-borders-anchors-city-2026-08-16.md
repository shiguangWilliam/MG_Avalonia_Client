# Tactical 地球追加功能汇总

> 日期：2026-08-16  
> 状态：**已实施**（F1/F2/F3/F4A 于 2026-08-16 落地，见 [`tactical-globe-f1-f4-implementation-2026-08-16.md`](./tactical-globe-f1-f4-implementation-2026-08-16.md) §8）  
> 底座：已迁移至 `OpenGlControlBase`（见 [`tactical-globe-opengl-migration-2026-08-16.md`](./tactical-globe-opengl-migration-2026-08-16.md)）  
> 相关：[`tactical-globe-tech-and-anchors-2026-08-16.md`](./tactical-globe-tech-and-anchors-2026-08-16.md)

本文把战役地球上 **四项追加能力** 收成一份产品/技术方案：选中旋转对准、国境线高亮、战役坐标锚点、城市全息投影。它们共用同一套 **lat/lon ↔ 等距圆柱 UV ↔ GL 球面** 契约，在 OpenGL 球之上分阶段叠加。

---

## 0. 总览

### 0.1 四项能力

| ID | 能力 | 一句话 | 建议优先级 |
|---|---|---|---|
| **F1** | 选战役旋转到指定位置 | 列表选中 → 地球平滑转到任务经纬度朝向相机 | P0 |
| **F2** | 对应国家国境线高亮 | 选中任务所属国（或战区）边界以青色描边强调 | P1 |
| **F3** | 战役坐标锚点 | 每个任务在球面上常驻可见导航锚，可点选 | P0 |
| **F4** | 城市全息投影 | 对准后切入城市级全息场景（mesh/投影板），非放大全球贴图 | P2 |

### 0.2 体验主流程

```
用户点选战役列表（或点锚点）
  │
  ├─ F3 锚点：该任务标记进入「选中」态
  ├─ F1 旋转：暂停自转 → 插值 Yaw/Pitch（+可选 Pitch）对准 (lat,lon)
  ├─ F2 国境：淡入该国边界高亮层（其余边界保持弱或隐藏）
  └─ F4 城市：可选继续缩放 / 淡入全息城市层（同 GL 上下文）
```

### 0.3 底座约束（已落地，四项必须遵守）

- 渲染：`TacticalGlobeGlControl`（`OpenGlControlBase`）+ Avalonia overlay（锚点/HUD）  
- 地理：`u = (lon+180)/360`，`v = (90-lat)/180`；与球顶点、贴图、射线拾取同源  
- 数据：`Battle.ini` → `GlobeLatitude` / `GlobeLongitude`；缺省仅开发回退哈希  
- **不做**：全球贴图像素硬放大当「城市」；Three.js / WebView

## 1. F1 — 选择战役时旋转到指定位置

### 1.1 目标

选中战役列表项后，地球在约 **0.6–1.2s** 内平滑旋转，使该任务坐标进入视口中心偏上（略留抬头空间给标签），并暂停自动慢旋；用户拖拽则取消动画、恢复手动控制。

### 1.2 现状

| 项 | 状态 |
|---|---|
| 坐标数据与 `GlobeNode` | 已有 |
| `FocusNode(index)` | **已有雏形**：每步按最短弧向目标经度 easing `0.12`，未做完整动画调度 / Pitch 对准 / 与选中联动收尾 |
| 列表 → `SelectedNodeIndex` | 已有双向同步 |

### 1.3 方案要点

1. **目标姿态**  
   - `targetYaw ≈ -longitude`（与现有 `Dir`/`FocusNode` 符号约定一致，实施时以当前 GL 公式为准做单测）  
   - `targetPitch`：由纬度推导并钳制在 `[-40°, 40°]`（避免极地翻车）  
2. **动画**  
   - 最短角插值（经度 ±180 跨越）  
   - ease-out cubic；定时器或与现有 33ms tick 合并  
   - 标志位 `_focusAnimating`：动画中忽略自转；PointerPressed 打断  
3. **触发**  
   - `SelectedIndex` 变化且对应节点有有效坐标 → 启动 Focus  
   - 锚点点击选中 → 同样触发  
4. **可选 L1**  
   - 对准完成后短时推进相机（FOV/`RadiusFactor` 等效），再保持或轻回弹——属增强，可并入 F1.5  

### 1.4 数据 / API

- 输入：`GlobeNode.LatitudeDegrees/LongitudeDegrees`  
- 宿主：`TacticalGlobeView.FocusNode` 升级为「完整动画」或 `FocusNodeAnimated`  
- 设置：可尊重 `GlobeAutoRotateEnabled`（Focus 期间强制暂停）  

### 1.5 验收

- [x] 切换列表项，地球转到对应陆地区域朝向相机（抽样 5 任务）— 单测固化目标姿态数学（伦敦/巴格达/悉尼/罗马/雷克雅未克），实际旋转待人工验收
- [x] 最短路径旋转，无「绕远」— `ShortestYawDelta` 单测覆盖 ±180 跨越
- [x] 拖拽可打断；打断后自转策略符合设置
- [x] 无坐标任务：不旋转或仅选中锚点，不报错 — 哈希回退坐标同样作为合法 Focus 目标

### 1.6 工作量

约 **0.5–1 人日**（在现有 `FocusNode` 上补完）。

## 2. F2 — 对应国家国境线高亮

### 2.1 目标

选中某战役时，其 **所属国家（或配置的战区边界）** 以战术青描边高亮；未选中时国境可弱显示或关闭，避免全球线网噪声。

### 2.2 现状

| 项 | 状态 |
|---|---|
| Natural Earth 国境线进 `world_geo.bin` / 烘焙进贴图 | 迁移文档 §13：烘焙进 albedo 的静态细线 |
| **按国动态高亮** | **未做** |
| 任务 → 国家 ISO 映射 | **未做**（需 INI 字段） |

静态烘焙国境 ≠ 运行时「选中某国发光」。F2 需要 **可切换的矢量/蒙版层**。

### 2.3 方案要点

**推荐：GPU 矢量线层（与球同 MVP）**

1. 离线从 Natural Earth admin_0 提取每国折线，按 ISO_A2/A3 索引进二进制（可扩展现有 `GMGB` 或旁路 `borders.bin`）  
2. 运行时只上传「当前高亮国」折线 VBO（或预上传全量 + 按国 draw range）  
3. Shader：青色 emissive + 轻微 bloom（或 overlay Avalonia 折线，精度略差）  
4. 淡入/淡出 200–300ms  

**备选（更轻、更糊）**

- 每国一张低分辨率边界 mask 纹理，片元里 `mix` 高亮——实现快，缩放易糊，剧院级勉强  

**不推荐**

- 改写整张 albedo 贴图来「画亮边界」——贵且与缓存冲突  

### 2.4 数据约定（建议）

```ini
; Battle.ini 任务节示例
GlobeLatitude=41.9
GlobeLongitude=12.5
GlobeCountry=IT          ; ISO 3166-1 alpha-2，驱动 F2
; 或
GlobeBorderId=vatican_theater   ; 自定义战区折线 id（覆盖国家）
```

无 `GlobeCountry` / `GlobeBorderId`：F2 跳过，仅 F1+F3。

### 2.5 验收

- [x] 选中带国家码任务 → 该国边界高亮，他国不抢戏 — GeoVerifyBorders 射线法 16/16（含负样本），运行时视觉待人工验收
- [x] 切换任务 → 高亮国切换，过渡可接受 — 220ms 淡入 / 260ms 淡出
- [x] 边界与贴图大陆套合（抽样沿海国）— 同源量化数据（同一 GeoConvert 量化公式），理论零偏移
- [x] 缺字段任务无崩溃、无错误高亮 — 单测覆盖非法/缺失 `GlobeCountry`

### 2.6 工作量

| 项 | 人日 |
|---|---|
| 国境按国切片与加载 | 1–2 |
| GL 线层 + 选中绑定 | 1 |
| INI 字段与缺省策略 | 0.5 |
| **合计** | **约 2.5–3.5 人日**（不含自定义战区美术） |

## 3. F3 — 战役坐标锚点

### 3.1 目标

当前列表中每个战役在地球上有 **常驻可见** 导航锚点；选中强调；点击锚点 = 选中该战役（并触发 F1）。

### 3.2 现状

| 项 | 状态 |
|---|---|
| `GlobeNode` + 列表同步 + 点击回写 | 已有 |
| Overlay 方标 / 选中括号 / 标签 | 已有（偏弱） |
| 真实坐标配齐 | 部分依赖 INI；缺则哈希 |
| 「导航锚」视觉强化 | **待做** |

### 3.3 方案要点

**视觉（Tactical `#2EE6C5`）**

- 默认：青色菱形/方标 + 细外环；深度缩尺  
- 锁定：muted 空心  
- 选中：反色/脉冲 + 角括号 + 短名  
- 背面：降透明或隐藏标签  

**行为**

- 显示范围 = 当前列表过滤结果（非全库刷屏）  
- Hover 放大 / tooltip  
- Click → `SelectedIndex` → F1 Focus  

**数据**

- 正式：`GlobeLatitude` / `GlobeLongitude`  
- 回退：哈希 + 可选调试「估算」标记  
- P0 策划任务：主线任务补全真实坐标  

### 3.4 验收

- [x] 打开战役窗即可看见当前列表锚点 — 菱形+外环强化可见性
- [x] 真实坐标抽样与陆地区域一致 — 共享 Dir() 投影，理论零偏移
- [x] 点击锚点 ↔ 列表一致并触发旋转（F1 已落地）
- [x] 哈希回退不崩溃

### 3.5 工作量

约 **0.5–1.5 人日**（表现强化）；INI 配坐标 **1–2 人日**（策划）。

## 4. F4 — 城市全息投影

### 4.1 目标

在 F1（及可选剧院缩放）之后，进入 **城市级全息表现**：可读的街区/地标级空间感，服务「创世之刻」叙事与任务氛围——**不是**把全球 `world_map` 放大。

### 4.2 现状

| 项 | 状态 |
|---|---|
| 全球球 + 贴图 | 已有 |
| 城市 mesh / 投影层 | **未做** |
| 任务级美术槽位 | **未约定** |

### 4.3 LOD 与表现选项

| 级别 | 内容 | 技术 |
|---|---|---|
| L0 | 全球球 + 锚点 | 已有 GL 球 |
| L1 | 剧院推进 | 相机/FOV（F1.5） |
| **L2 全息城市** | 任务局部场景 | 见下 |

**L2 推荐两条档（可并存）**

**A. 全息投影板（快、控成本）**

- 对准后在锚点附近淡入一张 **预烘焙全息城市图**（或短循环序列帧）+ 青边框/扫描线 shader  
- 数据：`GlobeCityArt=Assets/.../mission_xx_holo.png`  
- 工作量小，适合 P2 首发  

**B. 简化城市 mesh（表现上限高）**

- 同 `OpenGlControlBase` 上下文加载低面数 glTF / 程序化块体  
- 地面网格 + 若干建筑盒 + 全息线框材质（青 emissive）  
- 全球球可降透明度作背景或推远  
- 与后期「城市 mesh 场景」路线一致  

**明确不做（P2）**

- 真实卫星瓦片金字塔  
- 完整 OSM 建筑导入  

### 4.4 交互与状态机

```
Idle(L0)
  --选中--> Focusing(F1)
  --对准完成--> Theater?(L1 可选)
  --用户「进入」或自动--> CityHolo(L2)
  --取消/换任务/拖拽地球--> 退出 L2，回 L0/L1
```

退出时卸载 mesh / 释放投影纹理，避免显存驻留。

### 4.5 数据约定（建议）

```ini
GlobeLatitude=35.68
GlobeLongitude=139.69
GlobeCountry=JP
GlobeCityArt=Resources/DTA/Globe/Cities/tokyo_holo.png   ; A 方案
; 或
GlobeCityMesh=Resources/DTA/Globe/Cities/tokyo.glb        ; B 方案
GlobeCityScale=1.0
```

### 4.6 验收

- [x] 进入 L2 后可识别为「城市全息」而非糊成一片的全球贴图 — A 方案程序化板已落地（`GlobeCityArt` 自定义图待美术）
- [x] 与任务坐标空间关系正确（城市层锚在任务点）— 引线 + `ClampHoloBoard` 单测
- [ ] 退出/切换任务无泄漏、不卡死 — 逻辑已实现（overlay 绘制无位图驻留），人工回归待做
- [x] Classic / 无城市资源任务安全降级（仅 F1+F3）— 程序化板兜底，无资源依赖

### 4.7 工作量

| 方案 | 人日（程序） | 美术 |
|---|---|---|
| A 投影板 | 1–2 | 每任务 0.5–1 |
| B 简化 mesh | 3–5 | 每任务 1–3 |
| 状态机 + 与 F1 衔接 | 0.5–1 | — |

## 5. 推荐落地顺序

```
已完成：OpenGL 球 + 基础锚点绘制 + 坐标数据链
    │
    ▼
P0  F3 锚点视觉强化 + INI 坐标补齐（部分可并行）
    │
    ▼
P0  F1 完整旋转对准动画（基于现有 FocusNode）
    │
    ▼
P1  F2 国境高亮（需国家码 / 边界数据切片）
    │
    ▼
P2  F4 城市全息（先 A 投影板，再评估 B mesh）
```

依赖关系：

- F1、F3 互相增强，可同一迭代  
- F2 依赖国家/战区 id，不阻塞 F1/F3  
- F4 依赖 F1 对准完成；强烈依赖 OpenGL 底座（已满足）

## 9. 一句话

在 **OpenGL 地球** 上，用 **F3 锚点** 标出每个战役，用 **F1 旋转** 对准坐标，用 **F2 国境高亮** 标明国家语境，用 **F4 城市全息**（投影板或简化 mesh）呈现任务局部——四者共享 lat/lon 契约，分 P0→P2 落地，城市绝不靠放大全球贴图。
